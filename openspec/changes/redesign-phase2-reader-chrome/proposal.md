## Why

Reader controls need a coherent visual relationship with the Phase 1 theme while keeping the reading surface stable.

## What Changes

Restyle the toolbar, outline, reading settings and status chrome with shared tokens, restrained frosted surfaces and accessible control states.

## Capabilities

### New Capabilities

- `reader-chrome`: presentation and accessibility of HTML Reader chrome.

### Modified Capabilities

None.

## Impact

HTML Reader CSS and contrast contract tests. Existing controls, interactions, positioning and document layout remain unchanged.

## Non-goals

Reading typography, mathematics, paragraph chat, PDF preview, JavaScript and HTML changes.
