# Proposal: Reader Favicon Follows Browser Color Scheme

## Why
The HTML Reader favicon should represent the approved L mark and follow the user's browser color scheme, using contrasting tile and mark colors in both light and dark modes.

## What Changes
- Provide an SVG favicon for the HTML reader presenting the approved L mark.
- Present the mark on an ivory tile in light browser color scheme and on a charcoal tile in dark browser color scheme.
- Update HTML reader assets and index header to link the adaptive favicon.

## Capabilities
### New Capabilities
- `reader-favicon`: HTML reader favicon following browser color scheme.

### Modified Capabilities
None.

## Impact
HTML reader served assets and shell header. No compiler, editor, or backend service changes.
