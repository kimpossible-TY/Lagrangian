## Why

Paged preview chrome should share the Reader's visual language while leaving document rendering intact.

## What Changes

Restyle paged preview chrome with mirrored Reader tokens, accessible states and material fallbacks. Add contrast and visual capture fixtures.

## Capabilities

### New Capabilities

- `paged-preview-chrome`: themed, accessible paged preview controls.

### Modified Capabilities

None.

## Impact

The active paged frontend's CSS and Reader test tooling. The terminal Reader has no terminal-specific chrome CSS needing alignment.

## Non-goals

Document rendering, page geometry, interactions, Rust, terminal reading content, mathematics and chat.
